# Projets de cours en C#

Ces projets ont été développés dans le cadre de mes cours de .NET en deuxième année de bachelor CDEV à l'IPI Lyon.

## Motus
Ce projet consiste à créer un jeu type Motus : le programme sélectionne un mot de 6 à 8 lettres dans un dictionnaire donné. Il donne le nombre de lettres total du mot ainsi que sa première lettre et le joueur a six tentatives pour le deviner. À chaque tentative le programme indique si les lettres proposées font bien partie du mot et si celles-ci sont bien placées ou non dans le mot.
Pour plus de détails je vous invite à consulter la fiche énoncé dans le dossier.

## Mini jeu
Ce programme est un mini jeu de rôle très simplifié. Il est composé de plusieurs classes :
 - joueur
 - dé
 - Monstre niveau 1
 - Monstre niveau 2, qui hérite de la classe Monstre niveau 1
 - Programme
Pour ce qui est du déroulement du jeu, je vous invite à consulter la fiche énoncé dans le dossier.

## Vous voulez essayer
Prérequis : dotnet 10.
Pour lancer chacun des jeux, il vous suffit de cloner le repo, puis dans chacun des dossiers `dotnet run`.
